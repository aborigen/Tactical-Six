# Tactical Six | UI Component Manifest

This document outlines the high-fidelity UI components comprising the 6x6 tactical engagement arena.

## 1. Command Header (HUD)
*   **Tactical Emblem**: Brand identity icon with scaling hover effects.
*   **Live Score Matrix**: Real-time tally of White vs. Black victories and draws.
*   **Tactical EXP Badge**: Visual indicator of cumulative experience points (100 per win).
*   **Log Trigger**: Button to access the `HistoryDialog` for mission replays.
*   **Protocols Trigger**: Button to access the `RulesHelp` briefing.
*   **Command Settings**: Button to access the `SettingsDialog` (Themes, Skins, Audio).
*   **Mission Reset**: Quick-restart button for tactical re-engagement.

## 2. Combat Matrix (Board)
*   **6x6 Grid**: HSL-variable squares with algebraic coordinate notations.
*   **Piece Engine**: Multi-set renderer supporting Vanguard, Cyber, and Classical Staunton.
*   **Move Vector Overlay**: SVG-based arrow indicating the most recent maneuver.
*   **Highlight Layers**:
    *   *Selection*: Active unit focus.
    *   *Legal Moves*: Destination hints for the active player.
    *   *Tactical Hint*: AI-suggested move highlighting.
    *   *Last Move*: Source and destination markers.

## 3. Status Command Panel
*   **Deployment Indicator**: Shows active player turn (White Command vs. Black Command).
*   **Terminal State Display**: High-visibility banners for Checkmate, Stalemate, and Material Insufficiency.
*   **Analytics Trigger**: Integrated button to call the local AI search engine for a move suggestion.

## 4. Tactical Engine Panel (Sidebar/Bottom)
*   **Engine State Indicator**: Displays "Awaiting Directives" or "Calculating Vectors".
*   **Evaluation Readout**: Localized text explanation of the AI's positional heuristics.
*   **Difficulty Context**: Displays search depth based on the current commander rank.

## 5. Commander Profiles (Desktop Sidebars)
*   **White Command Card**: Displays Player One identity, win rate trajectory, and total tactical EXP.
*   **Black Command Card**: Displays Player Two (or Local Engine) identity and statistics.
*   **Session Stats**: Live tally of moves and draws for the current engagement.

## 6. Dialog & Overlay Systems
*   **Mission Briefing**: Configuration modal for game mode (PvP/PvE) and difficulty selection.
*   **Tactical Log**: Full-screen playback interface with algebraic notation registry and move-by-move scrubbers.
*   **Onboarding Protocol**: Multi-step cinematic walkthrough for new commanders.
*   **Settings Matrix**: Specialized UI for language switching, skin selection, and tactical vision (Themes).
