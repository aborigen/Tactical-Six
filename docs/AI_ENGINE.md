# Tactical Six | AI Engine Intelligence

The **Tactical Six** engine is a high-performance, deterministic tactical analyzer designed specifically for the 6x6 combat matrix. It executes entirely within the client-side environment, ensuring offline readiness and immediate response.

## 🧠 Strategic Core: Minimax Algorithm

The engine's decision-making process is based on the **Minimax** algorithm with **Alpha-Beta Pruning**.

1.  **Tree Search**: The engine explores all possible legal maneuvers from the current state.
2.  **Recursive Evaluation**: For every move, it simulates the opponent's best response, branching deeper into the future.
3.  **Alpha-Beta Optimization**: This technique allows the engine to "prune" (discard) branches that are guaranteed to be inferior to previously analyzed paths, significantly increasing search depth without sacrificing performance.

## 🎯 Evaluation Heuristics: The 6x6 Logic

Unlike standard chess engines, Tactical Six is calibrated for the high-intensity 6x6 grid.

### 1. Material Values
The relative strength of tactical units is weighted as follows:
- **Pawn**: 100

- **Rook**: 500

### 2. Piece-Square Tables (PST)
Positional awareness is encoded through a 6x6 value matrix for each piece type.
- **Central Control**: Knights and Bishops are incentivized to dominate the 6x6 center.
- **Pawn Progression**: Pawns gain exponential value as they approach the 1st/6th rank for Queen promotion.
- **King Safety**: The King is rewarded for staying in protected corners during the early mission phases.

## 🔄 Dynamic Draw Awareness

The engine is fully synchronized with tactical draw protocols:
- **Threefold Repetition**: The search algorithm detects if a move sequence leads back to the same board state for the third time. It evaluates these states as a score of `0` (Draw), allowing the AI to strategically force a draw when outmatched or avoid it when holding a material advantage.
- **Insufficient Material**: The engine recognizes terminal states where victory is no longer possible (e.g., King vs. King).

## 🚀 Move Ordering (MVV-LVA)

To maximize the efficiency of Alpha-Beta pruning, the engine utilizes the **Most Valuable Victim - Least Valuable Attacker** heuristic. It prioritizes the analysis of captures and promotions, hitting "cut-offs" faster and allowing for a deeper strategic lookahead.
