# Tactical Six | Version History Matrix

This document tracks the iterative deployment of the 6x6 tactical arena and its internal search engine.

## [1.6.0] - AI Hardening & UI Optimization
**Release Date: 2024-05-22**
### Engine & Logic
- **Recursive Refactoring**: Overhauled the Minimax search tree to include per-level move ordering, significantly increasing Alpha-Beta pruning efficiency.
- **Terminal State Scoring**: Implemented depth-weighted checkmate scores to ensure the AI pursues the most direct tactical path to victory.
- **Localized Evaluation**: Integrated the engine's tactical reasoning into the translation matrix, providing strategic feedback in both English and Russian.
- **Positional Heuristics**: Fine-tuned Piece-Square Tables (PST) to incentivize central control and king safety in the 6x6 matrix.

- **Orientation-Responsive Layout**: Introduced a side-by-side landscape mode for mobile devices, placing the engine analysis panel adjacent to the combat arena.
- **Portrait Refinement**: Replaced text-heavy buttons with icon-driven navigation for mobile portrait mode to prevent viewport clipping.
