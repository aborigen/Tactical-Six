
# Tactical Six | Changelog

All notable tactical upgrades to the 6x6 combat matrix are documented here.

## [1.28.0] - High-Fidelity Tactical Refinement
### Added
- **AI Engine Manual**: Deployed `docs/AI_ENGINE.md` detailing the search-and-evaluate architecture of the local Minimax engine.
- **Violet Tactical Tint**: Injected a deep violet hue into black tactical units within the Galaxy theme for superior visual cohesion.
- **Tactical Vector Animations**: Implemented smooth 500ms CSS transitions for piece displacements using a new absolute-positioned rendering layer.

### Changed
- **Programmatic Geometry**: Migrated the 'Geometric' piece set from static images to high-fidelity SVG components with unified trapezoidal bases and refined silhouettes.
- **Dynamic Color Matrix**: Replaced hardcoded tactical colors with theme-aware CSS variables (`--piece-black-fill`, etc.).
- **Audio Recalibration**: Synthesized sharper, more distinctive sound effects for moves, captures, and check alerts.

### Fixed
- **Intercepted Captures**: Resolved an issue where tactical units were blocking drag-and-drop events during capture maneuvers.
- **Strategic Baseline**: Realigned all pieces (including pawns) to a consistent bottom-horizon within the matrix squares.
- **Capture Logic**: Corrected a flaw in the move validator that prevented successful engagement with enemy units.

## [1.27.0] - Asset Engine Architecture
### Changed
- **Asset Logic**: Initial migration of tactical units to programmatic SVG components to support real-time theme reactivity.
